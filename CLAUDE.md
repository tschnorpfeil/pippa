# Working on Pippa

## Language on GitHub

Everything that appears on GitHub is in English: README and docs, the repository description, release titles and
release notes, commit messages, pull request titles and descriptions, issue and review comments, and code comments.
Write English even when the request came in German.

The exceptions are product content, not GitHub text: Pippa's German translations (`de.lproj`), the German website
(`site/`), German document analysis and its fixtures, and Pippa's German skills in `runtime/pippa-skills`.

Release notes follow [docs/releases/README.md](docs/releases/README.md): English only, starting with the same two
paragraphs on what Pippa does, which Mac she needs and which file to download.
