# Pippa 0.3.5

Text for the GitHub release. German first, then English. The 0.3.1 notes and the full 0.3 notes follow below them.

## Deutsch

**Neu in Pippa 0.3.5**

- **Mit dem Vorjahr vergleichen.** Findet Pippa keine Jahresspalten, fragt sie „Welche Spalte ist das Vorjahr?“ mit Knöpfen und rechnet dann selbst nach, statt zu schätzen.
- **„Zeig mir die Stelle“.** Bei „Summe prüfen“ zeigt Pippa den Ausschnitt der Tabelle mit der betroffenen Zeile gelb markiert, direkt in der Pille. In Excel bewegt sich nichts.
- **Rechnungen als Tabelle.** Gesamtbeträge mit „inkl. MwSt“ werden erkannt, ebenso englische Beträge wie „$1,234.56“ und Summen in der Zeile unter dem Wort. Ein ganzer Ordner mit Rechnungen geht jetzt auch.
- **Datumsangaben bleiben Datumsangaben.** Datumsangaben in Excel-Dateien bleiben Datumsangaben und werden nicht mehr mitgezählt. Liest Pippa nur einen Teil einer großen Tabelle, sagt sie das dazu.
- **Numbers.** Pippa schließt nur Fenster, die sie selbst geöffnet hat.
- **Als Brief.** Steht oben im Entwurf eine Anschrift, wird sie die Empfängeradresse statt eines gelben Platzhalters.

## English

**New in Pippa 0.3.5**

- **Compare with last year.** If Pippa finds no year columns, she asks "Which column is last year?" with buttons and then works it out herself instead of guessing.
- **"Show me where".** With "Check sum", Pippa shows the part of the table with the affected row marked in yellow, right in the pill. Nothing moves in Excel.
- **Invoices as a table.** Totals with "incl. VAT" are recognised, as are English amounts like "$1,234.56" and totals on the line below the word. A whole folder of invoices works now too.
- **Dates stay dates.** Dates in Excel files stay dates and are no longer added up. If Pippa reads only part of a large table, she says so.
- **Numbers.** Pippa only closes windows she opened herself.
- **As Letter.** If the draft starts with an address, it becomes the recipient address instead of a yellow placeholder.
