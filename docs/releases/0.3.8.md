# Pippa 0.3.8

Text for the GitHub release. German first, then English.

## Deutsch

**Neu in Pippa 0.3.8**

- **Erlaubnisse gehen nicht mehr unter.** „Was Pippa darf“ kommt jetzt auch, wenn du das Laden der KI auf später verschiebst. Schließt du die Seite, kommt sie bei einem späteren Start noch einmal. Offene Punkte haben einen blauen „Erlauben“-Knopf, und neben „Weiter“ steht, wie viele noch offen sind.
- **Klare Worte bei gesperrten Ordnern.** Hat dein Mac Pippa einen Ordner nicht erlaubt, sagt sie das beim Aufräumen und bringt dich mit einem Klick in die Systemeinstellungen.
- **Aufräumen mit sichtbarem Fortschritt.** Während Pippa deine Dateien ansieht, zeigt eine Anzeige direkt über dem „Ordnen“-Knopf, wie weit sie ist, welche Datei sie gerade liest und ob sie den Text eines Scans erkennt.
- **Aufräumen nutzt vorhandene Ordner.** Gibt es schon „Documents“, legt Pippa keinen zweiten Ordner „Dokumente“ daneben an. Eine Datei, die schon an ihrem Platz liegt, behält ihren Namen.

## English

**New in Pippa 0.3.8**

- **Permissions don't get lost anymore.** "What Pippa may do" now also appears when you put off loading the AI. If you close the page, it comes back once more at a later start. Open items have a blue "Allow" button, and next to "Continue" Pippa says how many are still open.
- **Plain words for blocked folders.** If your Mac didn't allow Pippa a folder, she says so when tidying and takes you to System Settings with one click.
- **Tidying with visible progress.** While Pippa looks at your files, a display right above the "Organize" button shows how far she is, which file she is reading and whether she is recognizing the text of a scan.
- **Tidying uses folders that are already there.** If there is a "Documents" folder already, Pippa doesn't create a second "Dokumente" next to it. A file that is already in its place keeps its name.
